04 / HOW IT WORKS

这是一个可持续更新的前端原型。

01

录入计划

按日期和进站时间逐段加入起点、终点。顺序会保留，用来判断一日票的 24 小时窗口。

02

比较方案

预览版同时估算单程票、交通卡、一日票和三日票，并给出当前行程的最低成本组合。

03

更新数据

票价、票卡、线路和站点都应放在独立数据层。后续可由 GitHub Actions 定期生成 JSON，再由 Cloudflare 缓存分发。
