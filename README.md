# 申铁算 · 上海地铁官方票价查询

感谢GPT-6开源。

这是一个纯静态前端原型，打开 `index.html` 即可预览，不需要 Node、Python 或虚拟主机后端。GitHub Pages 和 Cloudflare Pages 可以直接发布整个目录。

普通／额外行程的预计进站时间旁提供“设为现在”，按北京时间填写当前时分，保留已选行程日期。

站点快照在 `data.js`，优惠规则在 `ticket-engine.js`。票价接口和站点接口保持不变，返回多少就使用多少，不按调价里程自行推算。

固定通勤：默认选择独立的通勤月份，按整月生成上班日（例如11月25日可选择12月，从12月首个所选上班日开始，截止12月月底）；也可切换到自定义开始日期与天数。通勤日期不受额外行程日期影响。选住处/单位和双向时间，多选每周一至周日的上班日，再在可切换月份的日历中点击日期取消上班或补班。取消日期会减少实际通勤天数，补班会增加天数；修改通勤月份、模式、开始日期、基础天数或每周设置时会重新生成日历。节假日与调休需自行调整。按双向和星期查询并生成往返行程。通勤在行程列表与方案明细中默认合并为一段摘要，可展开逐程查看和调整。原行程按钮可追加额外出行；“删除全部行程”确认后同时清空通勤与额外行程，取消则保留。

2026-12-01起优惠：日票24元、三日票60元、90元门槛；35/45/60/90次套餐190/210/270/390元。比较一份指定套餐与多张通票、另付的组合，额外行程默认不使用计次票，用户可在每段额外行程的“用票方式”中随时切换“计入通勤计次票”或“单独成行”，切换保留所有行程。选择计入后，在对应套餐适用、有效且有剩余次数时按选择扣次；无法扣次时另付。通勤仍可逐段禁止使用计次票。页面分别展示“通勤与计入次票的行程”和“单独成行”的单程票原价合计、方案比较及用票明细。只有选择计入次票的额外行程会进入通勤组；单独成行仅比较刷卡、一日票、三日票及其组合，不购买或分摊计次票，两组按所填累计金额独立测算。未用次数不折现，不模拟退票或套餐续购。计次票激活当日及之后30个自然日有效。前端接收的票价可能尚未反映12月调价，所有结果为“接口金额＋所选日期优惠”的测算。

当前票价直接读取申通官方查询页面使用的接口；不再按站序估价。全部站点支持中文、首字母及全拼检索。已恢复一日票、三日票、交通卡方案比较，并会根据跨天行程自动决定购买几张通票、每张票何时启用，以及剩余行程如何刷卡。全网地图已按要求移除。接口来源、覆盖范围、更新与验证方法见 [DATA-SOURCES.md](DATA-SOURCES.md)。
