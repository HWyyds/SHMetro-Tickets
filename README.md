# 申铁算 · 上海地铁官方票价查询

感谢GPT-6开源。

这是一个纯静态前端原型，打开 `index.html` 即可预览，不需要 Node、Python 或虚拟主机后端。GitHub Pages 和 Cloudflare Pages 可以直接发布整个目录。

票卡、票价、站点和线路数据集中在 `data.js`。正式版建议由人工审核的 JSON 数据提交触发 GitHub Actions 构建，保留数据来源、公告日期和生效日期；不要让浏览器直接依赖第三方 API 密钥。

当前票价直接读取申通官方查询页面使用的接口；不再按站序估价。全部站点支持中文、首字母及全拼检索。已恢复一日票、三日票、交通卡方案比较，并会根据跨天行程自动决定购买几张通票、每张票何时启用，以及剩余行程如何刷卡。全网地图已按要求移除。接口来源、覆盖范围、更新与验证方法见 [DATA-SOURCES.md](DATA-SOURCES.md)。
